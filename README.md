# 안세호 백엔드 포트폴리오

정적 HTML 한 파일로 실행됩니다. CSS, JavaScript, 프로필 및 공개 아키텍처 이미지를 HTML에 포함했습니다.
외부 라이브러리 설치, API 키 또는 빌드 과정이 필요하지 않습니다.

GitHub Pages: Settings → Pages → Deploy from a branch → main / root.

## 자료 기준
- 이력서: 안세호_이력서.pdf 첫 페이지
- 넥스트그라운드 백엔드 전환형 인턴 공고: https://nextground.career.greetinghr.com/ko/o/101668
- 레이아웃 방향: https://yoohyeok.github.io/u-it/ 의 고정 사이드바·흰 본문 구성만 참고, CSS와 문구는 새로 작성
- 프로젝트: An1207 공개 저장소 및 본인이 허용한 비공개 원본 문서 우선
- 금융 AI의 2,400개 음성은 계획으로 구분하고, 운영 모델과 실험 후보를 구분
- Java / Spring / JPA / Redis 경험은 증거가 없어 추가하지 않음
- 전화번호, 상세 집주소, 개인 이력서 PDF 및 비공개 소스 원문은 공개 패키지에 포함하지 않음
- 자기소개서 문항과 김앤장 지원 문구는 사이트에 포함하지 않음
