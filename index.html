  • 고유 기사 61,545건: 학습 49,236 / 검증 6,155 / 테스트 6,154
  • TF-IDF 60,000차원 + 고정 EuroBERT 768차원, 최종 LR 학습
  • 모델 선택은 검증 Macro F1 기준, 테스트는 동일 기사로 평가
  • ONNX·OpenVINO 특징 추출을 원본과 대조하고 GPU 특징 코사인 유사도 0.999 이상 확인

웹에서 이어지는 처리와 저장

  • 기사 CRUD·검색·페이지 구분, 오래된 수정 요청은 HTTP 409
  • queued → running → completed/failed 상태와 화면 갱신
  • AI 호출을 직렬화하고 대기·진행 작업을 최대 10개로 제한
  • 재시작으로 남은 작업은 실패 처리해 재실행 가능, 분석 중 기사 삭제 차단
  • Ollama EXAONE 3.5 2.4B 한국어·영어 요약 및 긴 기사 분할·통합
  • 기사 수정 후에도 요청 시점 원문·버전 스냅샷과 분석 JSON 유지
  • MySQL LONGTEXT·JSON, 한글·이모지·64KiB 초과 UTF-8 본문 저장·재조회 검증

저장소 검증 기록: Python 테스트 41개, React 빌드, 실제 MySQL 및 분류기·EXAONE 연동 확인. 작업 실행기는 단일 FastAPI 프로세스 기준입니다.

분류는 학습된 영어 뉴스의 문체·어휘 패턴 판정이며 외부 사실 검증이 아닙니다. EuroBERT는 고정 특징 추출기이고, 요약은 별도 EXAONE 모델이 담당합니다.
